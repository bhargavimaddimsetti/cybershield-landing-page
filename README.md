# CyberShield - Responsive Landing Page

CyberShield is a responsive cybersecurity awareness landing page created using HTML and CSS.

## Project Features

- Responsive desktop layout
- Responsive mobile layout
- Cybersecurity awareness content
- Three cybersecurity safety tips
- Responsive image
- Mobile-friendly navigation
- No horizontal scrolling at 375px

## Technologies Used

- HTML5
- CSS3

## Responsive Design

The website is designed to work on both desktop and mobile screens.

The mobile layout was tested at a width of 375px.

## How to Run

1. Download or clone this repository.
2. Open `index.html` in Microsoft Edge, Google Chrome, or another web browser.

No additional installation is required.

## Project Purpose

This project was created as a responsive landing page development task to practice HTML, CSS, and responsive web design.
